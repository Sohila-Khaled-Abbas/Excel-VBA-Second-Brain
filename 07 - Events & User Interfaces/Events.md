# Events Architecture in VBA

> [!important]
> **Summary Statement**: Events in Excel VBA allow code to execute automatically in response to specific triggers in the application, such as changing a cell, opening a workbook, saving a file, or clicking a button.

---

## 🔗 Key Event Categories
- **[[Worksheet Events]]**: Responds to sheet actions (`Worksheet_Change`, `Worksheet_SelectionChange`).
- **[[Workbook Events]]**: Responds to workbook lifecycle events (`Workbook_Open`, `Workbook_BeforeClose`).
