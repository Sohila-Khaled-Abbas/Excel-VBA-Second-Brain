# Buttons (Form Controls vs. ActiveX)

> [!important]
> **Summary Statement**: Buttons trigger VBA subroutines when clicked. Can be implemented as Form Control buttons, ActiveX CommandButtons, or formatted worksheet shapes with assigned macros.
