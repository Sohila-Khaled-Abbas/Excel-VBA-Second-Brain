# Debugging in VBA

> [!important]
> **Summary Statement**: Debugging is the systematic process of inspecting code execution, validating assumptions, and isolating root causes of runtime and logical errors.

---

## ⌨️ Essential Debugging Hotkeys
- **`F8`**: Step Into (Executes code line-by-line).
- **`Shift + F8`**: Step Over (Executes a called procedure in one shot without stepping through its internal lines).
- **`Ctrl + Shift + F8`**: Step Out (Finishes the current procedure and returns to the caller).
- **`F9`**: Toggle Breakpoint (Pauses execution when reached).
- **`F5`**: Continue execution until next breakpoint or end.
- **`Ctrl + Break`**: Force-pause an unresponsive infinite loop.
