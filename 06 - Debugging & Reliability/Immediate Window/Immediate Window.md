# Immediate Window (`Ctrl + G`)

> [!important]
> **Summary Statement**: The Immediate Window is an interactive REPL inside VBE for evaluating expressions, querying object properties, and printing debug logs via `Debug.Print`.

---

## 💻 Power Usage Examples
- `?ActiveCell.Address`: Prints address of active cell.
- `?Sheets.Count`: Prints count of worksheets.
- `Call RunReport`: Directly triggers a sub procedure without running from a button.
