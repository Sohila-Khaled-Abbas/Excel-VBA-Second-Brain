- **VBA Naming Conventions (Hungarian Notation variant for VBA)**:
  - `ws`: Worksheet
  - `wb`: Workbook
  - `rng`: Range
  - `tbl`: ListObject (Table)
  - `lRow` / `lastRow`: Long integer row counter
  - `arr`: Array
  - `dict`: Scripting.Dictionary
