# File Automation

> [!important]
> **Summary Statement**: Automated file operations in Excel VBA encompass scanning directories (`Dir`), launching interactive file pickers (`FileDialog`), reading/writing low-level text streams (`FreeFile`), and batch-processing external workbooks.

- [[Text Files]]: Low-level byte and text streaming.
